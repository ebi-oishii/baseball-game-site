プライバシーポリシー

公開日 2026年11月27日

「プロ野球監督＆GMシミュレーター」の運営者は、本アプリおよび公式サイトにおいて、以下のとおり情報を取り扱います。

ゲームのセーブデータ

球団、選手、試合結果、進行状況、ゲーム内の所持アイテム等は端末内に保存されます。ゲームの利用にあたって運営者へのアカウント登録は不要です。運営者のサーバーにセーブデータを送信する機能はありません。

広告配信と外部送信

iOS版では、広告配信と視聴報酬に Google LLC の Google AdMob を使用します。Google Mobile Ads SDK は、広告の配信、効果測定、不正防止、動作の診断に、IPアドレス、IPアドレスから推定されるおおよその地域、端末・アプリの情報、利用可能な識別子、広告の表示・操作、診断情報を利用する場合があります。

本アプリからはパーソナライズされていない広告をリクエストします。Googleの同意フォームが提供される環境では、アプリ内メニューの「プライバシーポリシー」にある「広告のプライバシー設定」から選択内容を確認・変更できます。

  • Googleのプライバシーポリシー
  • Google Mobile Ads SDKのデータ開示

公式サイトの利用

本サイトは GitHub Pages を利用しています。サイトの配信に伴い、GitHubがIPアドレス等の接続情報を取り扱うことがあります。

お問い合わせで取り扱う情報

運営者は、メールアドレスやお問い合わせに含まれる情報を、回答、不具合の調査、対応履歴の管理に必要な範囲で使用します。これらの情報は対応に必要な期間または法令で求められる期間保管します。

個人情報の取扱い、開示、訂正、利用停止等に関するご請求は ebi.apps.support@gmail.com までご連絡ください。必要に応じてご本人であることを確認します。
